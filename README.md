## Executar localmente 📋

Você vai precisar de uma versão recente do Node.js e do npm.

```bash
git clone https://github.com/AdsonMozart/meu-portfolio.git
cd meu-portfolio
npm install
npm run dev
```

O Vite mostrará no terminal o endereço local para abrir no navegador.

### Scripts disponíveis

```bash
npm run dev      # inicia o servidor de desenvolvimento
npm run build    # gera a versão de produção em dist/
npm run preview  # visualiza localmente a versão de produção
npm run lint     # verifica o código com ESLint
```

## Configurar o formulário de contato 🔒

O formulário usa EmailJS. Para habilitá-lo, configure estas variáveis no arquivo `.env` local:

```env
VITE_EMAILJS_SERVICE_ID=seu_service_id
VITE_EMAILJS_TEMPLATE_ID=seu_template_id
VITE_EMAILJS_PUBLIC_KEY=sua_public_key
```

Use os valores da sua conta EmailJS e não publique credenciais privadas. Depois de alterar o `.env`, reinicie o servidor de desenvolvimento.
